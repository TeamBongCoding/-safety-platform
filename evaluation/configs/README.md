# 평가 설정

## 폭염 설정

`heat_fixtures.json`은 실제 날씨와 무관하게 평가 영상의 폭염 맥락을 재현하기 위한 명세입니다.

- `none`: 전체 영상에서 폭염 아님
- `heat_full_clip`: 전체 영상에서 폭염 맥락 적용
- `heat_reset_reentry`: 0~3초 폭염, 3~14초 비폭염, 14초 이후 다시 폭염

현재 운영 파이프라인은 기상 상태와 밝기로 폭염 맥락을 계산합니다. 오프라인 평가기를 만들 때 이 fixture를 읽어 `in_heat` 값을 영상 시간 기준으로 주입해야 합니다. 실제 폭염 날씨에서 촬영할 필요가 없습니다.

## 구역 설정

`zone_fixture` 값이 `work_area` 또는 `no_entry`인 영상은 바닥에 밝은 테이프로 사각형 또는 사다리꼴 경계를 표시합니다.

촬영 후 각 영상 첫 프레임을 기준으로 경계 꼭짓점을 정규화 좌표 `(x / width, y / height)`로 기록할 예정입니다. 카메라를 움직이면 좌표가 달라지므로 구역 관련 C006~C016 촬영 중에는 삼각대와 줌을 고정해야 합니다.

권장 화면 배치는 다음과 같습니다.

- 테이프 구역: 화면 오른쪽 절반
- 일반 이동 통로: 화면 왼쪽 절반
- `inside`: 양발이 테이프 내부에 보이도록 촬영
- `near`: 발이 테이프 바로 밖을 지나가되 테이프를 밟지 않도록 촬영
- `outside`: 구역과 사람 사이에 사람 한 명 폭 이상의 간격 유지

영상이 준비되면 실제 프레임에 맞춰 구역별 JSON fixture를 추가합니다.
